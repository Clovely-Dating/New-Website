# Refresh Clovely to the Prism Glass identity

## What will change
- Keep every existing section and all current copy unchanged.
- Replace the current plum, sage, coral, and taupe theme with the style guide’s ink, icy background, coral, sky, tangerine, lilac, gold, sage, and mist palette.
- Apply the new translucent “Prism Glass” visual system: floating soft color fields, glass surfaces, ink typography, rounded controls, and gentle depth without gradients.
- Switch typography to Bricolage Grotesque for display text and Instrument Sans for body text.
- Replace the current clover mark throughout the site and favicon with the supplied blue, orange, lilac, and gold logo.
- Rebuild the landing-page app preview as an original coded interface inspired by the supplied Discover and voice-chat mockups, including blurred photos, voice waveforms, match alignment, and glass controls.
- Restyle the App Store download page to the same identity and replace its current generic image with the new app presentation.

## Quality checks
- Verify the home and download pages at desktop and mobile sizes.
- Check that all copy remains unchanged, text remains readable, controls do not overlap, animation respects reduced-motion settings, and both pages load without browser errors.

## Technical details
- Define the new palette, glass recipes, shadows, and typography as global semantic design tokens.
- Build the mockup from accessible HTML and CSS rather than embedding the reference screenshots directly.
- Store the uploaded logo through the project asset flow; create a separate square favicon copy in `public/`.
